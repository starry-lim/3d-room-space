# 3d-room-space

An interactive 3D study room built with Three.js, React, and TypeScript — designed as a cozy corner to focus, exercise, and hang out with Miso the cat.
Fully generated by AI

---

## ✨ Features

- **Focus & Study Mode**: Sit at the desk or on the floor pouf with a built-in Pomodoro timer, interactive notebook/lamp, and warm coffee mug.
- **3rd-Person Avatar Customizer**: Choose from 8 rigged characters and customize hair/fur, outfit colors, and accessories (`headphones`, `glasses`, `scarf`).
- **Exercise Corner**: Track workout time on the Yoga Mat, Dumbbell Rack, or Spin Bike with live stopwatch & workout logs.
- **To-Do Board & Pinned Widget**: Write tasks on the 3D wall corkboard (`L`) or pin a compact checklist directly on screen.
- **Miso the Cat & 5 Toys**: Pet or call Miso (`F`) and play with the yarn ball, feather wand, scratching post, cardboard box, and laser pointer.
- **Dynamic Atmosphere**: Switch between Morning, Golden Hour, and Night skies with synthesized WebAudio lo-fi radio & ambient sound effects.

## 🎮 Controls

| Key / Action | Description |
| --- | --- |
| `WASD` / `Arrows` | Walk (`Shift` to run, `Space` to jump, `C` to squat) |
| `Click` / `E` | Interact with furniture & items |
| `V` | Toggle 1st / 3rd person camera |
| `F` | Call Miso |
| `L` | Open To-Do list |
| `P` / `T` | Start/pause timer / Open timer panel |
| `M` | Mute / unmute audio |

## 🛠️ Tech Stack & Local Setup

- **Stack**: React 19, TypeScript, Vite, Tailwind CSS, Three.js
- **Run locally**:
  ```bash
  npm install
  npm run dev
  ```
- **Build single-file bundle**:
  ```bash
  npm run build
  ```
